# Secure Food Delivery Lab

This repository contains starter code for the **Secure Analytics API Lab**.

Students must complete the following tasks.

---

## Task 1 (15 Marks)

Implement password hashing using bcrypt in:

src/models/user.model.js


## Task 2 (15 Marks)

Implement JWT login authentication in:

src/controllers/auth.controller.js

Test using Postman.


## Task 3 (30 Marks)

Create a MongoDB aggregation pipeline using:

- $match
- $lookup
- $facet
- $group
- $sort
- $limit

File:

src/controllers/analytics.controller.js

---

## Running the Project

1. Clone the repo
2. Run `npm install`
3. Copy `.env.example` to `.env`
4. Run `node src/server.js`
